# 验收：download → media → analysis

主验收终点为 `analysis.ok`，三个前置门控缺一不可。旧 `watch.ok`、固定机械分镜、仅 schema 合法都不能证明学习完成。

| 阶段           | 必须核验                                                                                                                                                                                         | 必须拒绝                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| download       | 来源身份；非空原文件；实际 SHA256 与清单及门控相同                                                                                                                                               | 文件缺失、路径越界、哈希不符                                 |
| media          | 实际 probe 有视频流；正的时长/尺寸/帧率；抽帧文件存在且哈希相符；frame_index 与 pts_ms 来自原视频                                                                                                | 文本伪装 MP4、缺工具、probe 失败、空帧、超时、默认参数       |
| analysis       | 已验证帧输入真实视觉模型；记录 provider/model；receipt 留响应 ID、实际提交帧与 finish_reason=stop；门控绑定 spec/receipt 文件哈希；JSON 结构合法；所有引用在帧清单内且时码匹配；源文件身份仍相同 | 模型失败/超时、错误结构、虚构引用、MECH_PROBE、仅旧 watch.ok |
| remake（可选） | 明确开启；analysis.ok；allowed_use 允许                                                                                                                                                          | 默认跳过不是失败；禁止默认强制生成                           |

## 必测失败路径

- `E_NOT_VIDEO`：普通文本改名 `.mp4`，不能生成 media.ok 或 analysis.ok。
- `E_PROBE_MISSING`：探测/抽帧可执行文件缺失，不回退 1 秒 / 1 fps / 1 帧。
- `E_PROBE_FAIL`：工具非零退出或响应没有有效视频信息，阻塞分析。
- `E_TIMEOUT`：超时终止本次操作，不把半成品视为成功。
- `E_MODEL_FAIL`：调用失败/空响应/无效 JSON，不标“已学”。
- `E_MODEL_BAD_REF`：引用未发送帧、帧哈希错误或时码不符，拒绝成功。
- 上游文件被修改、同 video_id 旧成功记录残留：重新核验当前内容，禁止借旧 gate 绕过失败。

## 证据边界

单元测试、注入事件、脚本模型输出只证明各自契约。真实成功验收需合法视频、真实 probe/抽帧、实际视觉模型响应、引用核验、GUI 状态及磁盘门控一致。报告分别列出已执行、未验证和失败，不以演示录制替代真实链路。

兼容入口 `scripts/accept_download_watch.mjs` 只读核对现存成果；`scripts/watch_gate.mjs` 不再签发任何成功 gate。验收不会修改、删除或补造产物。
