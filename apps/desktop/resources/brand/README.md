# Lancer artwork

The project owner supplied `lancer-icon-source.jpg` on 2026-10-30 and selected it for the Lancer App in the open-source preparation request. `provenance.json` records its SHA-256. `icon.png`, `icon.icns`, the sidebar mark and default Lancer avatar are format/size conversions of that file; the design was not redrawn.

The default research and creative assistant portraits are simple SVG glyphs authored for this project under its MIT license. Users can still upload their own portraits. Earlier character artwork is not included in the public source candidate; its local backup is retained outside the export.

Provider names and marks identify the configured services; the code license does not grant trademark rights. User-uploaded portraits, video references and downloaded material are not release assets.
