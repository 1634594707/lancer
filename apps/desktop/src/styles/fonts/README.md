# Lancer light UI fonts

Locally bundled Latin variable WOFF2 subsets; no renderer network requests or machine-wide font installation.

- `inter-latin-wght-normal.woff2`: `@fontsource-variable/inter@5.2.8`, https://registry.npmjs.org/@fontsource-variable/inter/-/inter-5.2.8.tgz
- `jetbrains-mono-latin-wght-normal.woff2`: `@fontsource-variable/jetbrains-mono@5.2.8`, https://registry.npmjs.org/@fontsource-variable/jetbrains-mono/-/jetbrains-mono-5.2.8.tgz

Both use SIL Open Font License 1.1; the original licenses are included alongside the fonts. `lancer-light.css` applies them only within the light prototype shell. Chinese text uses the platform CJK fallback (PingFang SC on macOS).
