# 视频学习：会话与交付物

左侧按模块显示会话列表。下载、分析和复刻结果留在对应会话中，右侧 GitTree 保留过程节点、失败与重试记录。

| 内容                       | 出现条件                                                  | 入口                     |
| -------------------------- | --------------------------------------------------------- | ------------------------ |
| 原视频                     | `download.ok`、`passed`，且存在带 SHA-256 的 `source.mp4` | 所属会话的文件卡片       |
| 复刻视频                   | `remake.ok`、`passed`，且存在带 SHA-256 的 MP4            | 所属会话的文件卡片       |
| 下载、分析、交接、失败重试 | 当前任务已记录的阶段和证据                                | 会话过程行与右侧 GitTree |

卡片默认显示产物类型、文件名和打开按钮。文件路径与完整校验值放在可展开的“文件信息”中；打开失败在当前卡片提示。文件打开复用现有的主进程路径校验边界。

尚未出片、失败、运行中或未验证的产物不会被标记为交付。只有代码或回执的成功 gate 也不等于生成了视频。同类同哈希去重，不同成片保留。未生成产物时仍正常显示会话列表。

## 所属关系

投影读取 `VideoLearnSnapshot.relayTree.artifacts`，仅接受记录了当前工作区与会话所有者的视频快照。其他会话不会继承当前工作区的下载状态或交付卡片。本功能不是跨历史任务的全量媒体目录。

## 验证

- 单元测试：`apps/desktop/tests/unit/video-deliverables.spec.ts` 与 `live-process-flight.spec.ts`。
- Electron：`apps/desktop/tests/core/video-deliverables.spec.ts` 覆盖下载、仅代码未出片、失败留树、成功出片与文件信息。
- `apps/desktop/tests/core/ui-shell.spec.ts` 检查模块、助手、会话导航与草稿隔离。

合成 gate 的 Electron 测试只证明状态投影和交互。实际下载、模型执行、豆包原生接管和外部播放器需要各自实测，不能用合成文件代替。
